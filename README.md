# Telecom-Customer-Churn

Intern ID: CITS1152

## Project Overview

This machine learning project predicts whether a telecom customer is likely to churn (leave the service) or not.

The project uses Logistic Regression for classification and analyzes customer data to identify churn patterns.

## Dataset

The dataset contains customer information such as:

- Gender
- Senior Citizen
- Partner
- Dependents
- Tenure
- Phone Service
- Internet Service
- Monthly Charges
- Total Charges
- Contract Type
- Payment Method

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning Model

Algorithm Used:

- Logistic Regression

## Steps Performed

1. Data Loading
2. Data Preprocessing
3. Label Encoding
4. Train-Test Split
5. Model Training
6. Prediction
7. Accuracy Evaluation
8. Confusion Matrix Analysis

## Results

Model Accuracy: 81.62%

The model successfully predicts customer churn behavior using customer demographic and service information.
